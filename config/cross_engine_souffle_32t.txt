# =============================================================================
# config/cross_engine_souffle_32t.txt
#
# Comprehensive FlowLog (compiler) vs Souffle (compiled, parallel) sweep —
# NON-DOOP workloads. Every pair has BOTH a flowlog program
# (programs/oracle/flowlog/<stem>/default.dl) AND a souffle program
# (programs/oracle/souffle/<stem>.dl), so each yields a real side-by-side bar
# (time + peak RSS).
#
# Run:  WORKERS=32 NUM_RUNS=3 \
#         bash scripts/cross_engine.sh --fresh --keep-datasets \
#              --engines=souffle config/cross_engine_souffle_32t.txt
#
# Both engines get 32 threads: FlowLog `-w 32`; Souffle `-j 32` at BOTH compile
# (`souffle -o bin -j 32`, gates the pfor/libgomp expansion) and runtime
# (`bin -j 32`). See scripts/engines/souffle.sh.
#
# DOOP context-insensitive points-to (the 20 DaCapo apps) is run SEPARATELY via
# scripts/context_insensitive_compare.sh: its souffle program aborts on the
# keep-spec input files the corpus omits (FlowLog treats them as empty), and it
# uses `.output` (full relations, multi-GB) rather than `.printsize`, so it needs
# the dedicated overlay + tmpfs output-dir harness. Those rows are merged into
# the same comparison CSV afterwards (same metric: FlowLog solve-time vs Souffle
# wall, peak RSS via /usr/bin/time -v).
#
# Excluded on purpose: pairs Souffle can't run (cc/sssp/reach=twitter — flowlog-
# only, [souffle:skip]) since there is nothing to compare against.
# =============================================================================
